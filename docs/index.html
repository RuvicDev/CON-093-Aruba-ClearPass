Conector Aruba ClearPass (NAC) — Guía de configuración

Última actualización: octubre 2026

¿Qué es y para qué sirve?

El conector Aruba ClearPass permite que el agente de Ruvic consulte y controle el acceso a la red: ver endpoints, autorizar o revocar dispositivos y revisar o desconectar sesiones activas. Puedes pedirle cosas como:

  • "Autoriza la impresora con MAC 12:34:56:78:90:ab (ticket 881)."
  • "Bloquea el portátil robado y desconéctalo de la red."
  • "¿Desde qué dispositivos está conectada ana.perez?"

Operaciones soportadas:

OperaciónQué hace
endpoints.listConsulta endpoints por estado o por MAC
endpoint.authorizeDeja un dispositivo en estado Known (escribe)
endpoint.revokeDeja un dispositivo en estado Disabled (escribe)
sessions.listConsulta sesiones activas
session.disconnectDesconecta una sesión activa (escribe)
Estas acciones cambian el acceso real a la red Revocar o desconectar deja sin red a un dispositivo. El agente solo lo hace cuando se lo pides y registra el motivo.

Prerrequisitos

  • ClearPass Policy Manager 6.x con la API REST habilitada.
  • Acceso de administrador a ClearPass Guest para crear el perfil de operador y el API Client.
  • Una regla de Enforcement que deniegue los endpoints con estado Disabled.

Configuración en el fabricante

Vas a crear un perfil de operador acotado y un API Client con grant type Client credentials.

  1. Crea el perfil de operador.

    En ClearPass Guest → Administration → Operator Logins → Profiles, crea "Ruvic API" con: API Services → Allow API Access; Policy Manager → Identity → Endpoints (lectura/escritura); Active Sessions (lectura y desconexión).

  2. Crea el API Client.

    En Administration → API Services → API Clients → Create API client, elige grant type Client credentials y el perfil "Ruvic API". Copia el Client ID y el Client Secret.

    [ Captura: creación del API Client en ClearPass Guest — reemplazar por assets/img/clearpass-apiclient.png ]
  3. Verifica la regla de bloqueo.

    En el servicio de Enforcement, confirma que existe una regla Endpoints Repository:Status EQUALS Disabled que deniega el acceso.

Permisos requeridos

Principio de mínimo privilegio: el perfil de operador solo necesita lo siguiente. No uses Super Administrator.

PermisoPara qué lo usa el conector
API Services → Allow API AccessUsar la API REST
Identity → EndpointsConsultar, autorizar y revocar endpoints
Active SessionsConsultar y desconectar sesiones

Configuración en Ruvic

Entra a Settings → Conectores, busca la tarjeta Aruba ClearPass (NAC) y pulsa Configurar. Diligencia el formulario con los valores de la sección anterior:

Campo del formularioValor
URL de ClearPassURL del servidor ClearPass, ej. https://clearpass.miempresa.com
Client IDClient ID del API Client
Client SecretClient Secret. Se guarda cifrado
Verificar certificado SSLDesactívalo solo con certificados autofirmados en redes de confianza
Timeout de conexión (segundos)Opcional; 15 segundos por defecto

Guarda y pulsa Probar conexión: la plataforma valida las credenciales y el acceso.

[ Captura: formulario del conector Aruba ClearPass (NAC) en Settings → Conectores — reemplazar por assets/img/aruba_clearpass-form.png ]

Verificación

  1. Test de conexión exitoso.

    El botón Probar conexión debe responder con éxito y la tarjeta debe quedar en estado Configurado.

  2. Prueba mínima con el agente.

    Abre una conversación nueva y pídele:

    "¿Cuántos endpoints deshabilitados hay en ClearPass?"

    El agente debe responder con datos reales. No le pidas revocar ni desconectar durante la prueba.

Solución de problemas

Mensaje / síntomaCausa probable y solución
"Client ID o Client Secret inválidos"Revisa las credenciales y que el API Client use el grant type Client credentials.
"El perfil de operador … no tiene permiso" (403)Agrega Endpoints o Active Sessions al perfil de operador.
El dispositivo revocado sigue conectadoEl cambio aplica en la siguiente autenticación. Desconecta su sesión para expulsarlo ya.
"mac inválida"Usa el formato 12:34:56:78:90:ab (también se aceptan guiones o sin separadores).

Preguntas frecuentes y notas de seguridad

¿Puede el agente desconectar a todos los usuarios?

No. El conector solo desconecta una sesión por ID y nunca usa la desconexión masiva.

¿Qué diferencia hay entre revocar y desconectar?

Revocar marca el endpoint como Disabled para futuras autenticaciones; desconectar expulsa la sesión actual.

¿Qué hago si el Client Secret se filtra?

Regenera el secreto del API Client en ClearPass Guest y actualízalo en el formulario.
